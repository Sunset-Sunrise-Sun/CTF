## 实施决策与复审点

系统级调用没有题目外键，因此新增独立 `model-audit.sqlite3`。它在首次调用时创建，使用分别只追加的开始和终结表。SQLite 完整同步提交开始记录后才进入传输。仅有开始记录时投影为 `unknown`。现有 001/002、Event canonical、Store 和 ArtifactStore 保持原契约。

账本终结与题目事件属于两个写入步骤。服务中断或事件写入失败时，已有账本事实仍可通过调用 ID 查到，缺少题目事件关联的预览和 ZIP 标记不完整。该账本依赖本机文件系统权限与 SQLite 约束，没有外部完整性签名。P1 的工具状态与事件原子提交是单独要求。

A1/A2 门禁依据服务器读取的题目等级。比赛官方规则仍需要用户确认后设置等级。当前客户端确认适用于本地单用户工作台，可信人工审批身份机制属于 P1。记录中的 token 用量来自 Provider 提供的合法计数，缺失时为 null。
