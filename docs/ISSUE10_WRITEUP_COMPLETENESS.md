# Issue #10: Writeup completeness and evidence mapping

## Status

Implemented in the issue branch; no commit of main, no merge of PR #6/PR #9, no real
challenge/Flag/API access.

## Completeness model

Each Writeup now returns a `requirements` matrix with one of:

- `proven`: an audit event or verified Artifact satisfies the requirement;
- `missing`: required evidence is absent, with a remediation instruction;
- `not_applicable`: explicitly not expected, with a reason.

`missing_requirements` remains for older clients and is derived from the matrix;
N/A items never appear there. Synthetic connectivity challenges use
`evidence_profile=synthetic_connectivity` (or the legacy synthetic-connectivity
name fallback) and mark only `core_code` and `flag_capture` N/A with explicit
reasons. The system does not invent code, a Flag or a platform verification.

`manual_operation` and `platform_verification` are only proven by their own
recorded evidence (manual-operation event / platform-verification Artifact);
tool approval/execution alone does not make them proven.

## Counts and mapping

- `tool_execution_count` counts execution IDs (8 in the reported synthetic case).
- `unique_tool_output_artifact_count` counts distinct output Artifact IDs
  (7 in that case, because two executions shared byte-identical output).
- Imported ZIP exports now separate:
  - `original_archive_entries` / `original_archive_entry_count` (only entries
    from the uploaded archive);
  - `generated_manifest` (`generated-manifest.json`, generated by the import
    system, explicitly `is_original_archive_entry=false`).

## Human writeup

The human draft remains the final `writeup.md` byte-for-byte. Export also writes
`writeup_generated.md`, and the manifest now records:

- human version, SHA-256, size and saved time;
- generated SHA-256/size;
- `human_generated_diff` (changed flag, line counts, SHA-256, bounded preview,
  `human_never_overwritten=true`).

Saving is still optimistic-versioned; a stale editor receives 409 and never
overwrites the server draft.

## Regression coverage

New tests: `backend/tests/test_issue10_writeup_completeness.py`.

Covered:

- synthetic fixture without Flag/independent code: N/A reasons and no fabricated evidence;
- real-challenge fixture: no N/A pass; complete only with actual approach/manual/code/execution/Flag/platform evidence;
- 8 executions / 7 unique output Artifacts;
- original ZIP entry vs generated import manifest;
- human draft byte-exact export and diff disclosure;
- missing-item remediation instructions.
