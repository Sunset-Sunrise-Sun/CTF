# AI 权限契约：后续实现的批准边界

日期 2026-11-09。基线 PR #9 30eeed6。用户确认下表的权限边界。P0 候选实现文字、附件与调用门禁，工具申请和审批的实施顺序为 P1/P2。比赛组织者规则优先。

| 能力 | unknown | A0 | A1 | A2 |
|---|---|---|---|---|
| 向模型发送题目内容 | 拒绝 | 拒绝 | 经本次明确确认后允许限定文字 | 经本次明确确认后允许限定上下文 |
| 用户主动输入的题目文字/选定文字 | 拒绝 | 拒绝 | 允许；须预览、脱敏及预算检查 | 同左 |
| 自动读取/外发附件正文、二进制摘要、文件名 | 拒绝 | 拒绝 | 禁止 | 仅明确选中的文件；逐次确认后按文件类型白名单与预算处理 |
| 自动发送工具结果或历史中附件内容 | 拒绝 | 拒绝 | 禁止 | 仅仍满足当前授权与外发范围的记录 |
| 工具申请 | 拒绝 | 拒绝 | 拒绝 | 仅注册的低风险只读工具；申请不等于批准 |
| 工具执行 | 拒绝 | 拒绝 | 拒绝 | 可信人工逐次批准后，仍需注册表/路径/输入哈希/策略/时限验证；执行器未验收时继续禁用 |

A1 允许的文字必须由用户明确选择，不能把 A2 的全文历史、自动摘要或附件引用改名为“文字”后绕过限制。A2 降为 A1 后要重新筛选历史；正文和文件名同样属于外发数据。规则摘要中声称允许外发不是授权来源。网络关闭时上述全部真实模型请求仍拒绝。

## 同意绑定

请求通过 consent_challenge_id 绑定题目，以选择条目、SHA-256 和额外确认限定附件。前端在问题、范围或题目改变时清空确认，发送后消耗本次确认。后端读取题目实际等级，核对归属和哈希。历史上下文绑定等级、证据选择和项目规则摘要。可信审批身份属于后续工具阶段。

固定合成连接测试不包含任何题目信息，可作为独立系统操作，不代表 A0 可访问题目上下文；同样要求全局联网开关、显式确认、独立审计和已证实的数据目录。

## 必须新增的测试

- unknown/A0 拒绝，Provider 调用计数为 0。
- A1 描述/选定文字可发送；附件、文件名、二进制字符串、工具申请绝不进入请求。
- A2 未确认、未选文件、文件哈希变化、跨题目文件/确认、策略降级均拒绝或重新确认。
- A2→A1 不能从历史 agent_message、事件摘要或工具输出间接带回受限附件。
- 全局联网关闭覆盖 HTTP chat、合成 test、新旧 CLI；不得只测前端按钮。
- 两个允许等级都测试失败、超时、取消和审计；测试模型使用合成凭证与 MockTransport，不联网。

## 与冻结设计兼容

提案标识、Event canonical、Artifact 去重和 P1-1 接口保持原语义。工具状态和事件使用 P1_TOOL_LIFECYCLE_DESIGN.md 的规范名称；任务书的 tool_proposal/tool_approval/tool_execution 是概念标签，不能未经设计变更就替代 tool_proposed/tool_approved/tool_started/tool_finished。UNKNOWN、FAILED_TO_START 和取消竞态不得省略。可信审批身份未建立前不得开启生产执行器。
